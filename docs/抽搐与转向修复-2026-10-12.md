# 极限竞速8：行驶抽搐与转向响应修复

项目：`D:\极限竞速8\极限竞速8`。

用户反馈行驶抽搐、操控笨重，并明确表现为转向慢、反打跟不上。本次修复两处对应问题。

## 改动

- Worker 状态中的 `alpha` 已包含未完成物理步的剩余时间，而快照时间戳又减去了同一份时间。渲染端随后再次累加时间，导致插值提前到达终点并停住。快照改用本次采样时刻，剩余时间只计一次。正常步进和补算多个物理步均有回归检查。
- 转向滤波系数从 8 调整为 14，保留连续变化、高速转角限幅及横摆加速度上限。60Hz 检查中，输入达到 95% 从 383ms 缩短至 217ms；满舵反打越过中点从 100ms 缩短至 50ms，达到反向 80% 用时 167ms。数值描述的是输入响应，不是所有速度和路面上的车身转向时间。
- 更新原有转向自检目标，并增加 `tools/handling-check.mjs`。行驶采样工具改为明确启动本项目 exe、使用隔离积分目录；采样帧之间累计真实碰撞标记，避免慢帧中撞墙后离开的正常减速被误报为自由行驶抽搐。

## 验证

- 新增检查在修复前复现插值时间重复、转向建立慢和反打滞后三项失败，修复后全部通过。
- 715 项自检通过。
- 真实 Edge 游戏连续油门采样：4408 个采样帧，其中 4232 个自由行驶帧；异常速度倒退 0，超物理上界的位置跳跃 0，浏览器异常 0。这个采样检查物理状态，渲染时间计算由单独的回归检查覆盖。
- Worker 固定步、300ms 主线程阻塞期间独立运行、网络代理、时钟、同步、镜头与此前驾驶同步回归通过。
- Vegas、Spa AI 一圈完赛、完赛巡航、事故车避让及出界脱困检查通过。
- 重编译 exe；全部 21 个内嵌资源通过 HTTP 字节数与 SHA-256 校验。

## 使用与范围

重启项目 `forzalan.exe`，游戏页面按 **Ctrl+F5** 刷新后重新开局。转向与反打会比原先更快建立。

尚未验证用户实际显示器、手柄及两台实体设备的联机手感；持续掉帧仍可能影响画面流畅度。本次没有增加画质选项或改变赛道与积分数据。
