## 踩坑：默认端口 8080 被 Steam 占用（易复现，务必记住）

用默认 `./forzalan.exe`（绑 `0.0.0.0:8080`）启动后，**本机 `http://localhost:8080/`
打不开游戏**。症状：`/` 返回 200 但 `/js/main.js` 返回 **404**。

根因：`steamwebhelper.exe` 占了 **`127.0.0.1:8080`**（Steam 内嵌 Chromium 的
remote debugging 端口）。服务端绑的是 `0.0.0.0:8080`，Windows 下
**`127.0.0.1` 比 `0.0.0.0` 更具体，优先级更高** -> 本机回环请求被 Steam 截胡。
验证：`curl http://127.0.0.1:8080/` 返回 `<title>CEF remote debugging</title>`；
走局域网 IP `http://192.168.68.229:8080/` 则一切正常（Steam 只绑回环）。

**正解：起服务时避开 8080**，本项目验收/游玩统一用 **8099**：
```bash
PORT=8099 ./forzalan.exe    # 本机 http://localhost:8099 + 局域网 http://<ip>:8099 都正常
```
排查同类问题的手法：`netstat -ano | grep ":<port>\b"` 看是否**多个 PID**，
`tasklist //FI "PID eq <pid>"` 认领进程名。

### 改动

### 涡线踩的三个坑（都靠实测抓出来，值得记）
1. **发射点写错量级**：先按"车身半宽 0.9 / 半高 0.6"猜，实际车身是
   `BoxGeometry(1.82, 0.5, 4.0)` + 尾翼在 `y=0.46,z=-1.92`。改成尾翼端板 `x=±1.00,y=0.50,z=-1.95`、

3. **加色 0.25 + 0.06m 宽在亮灰路面上等于隐形**。做了"响铃"实验：临时改
   NormalBlending + 纯红 + alpha 1 + 宽 0.40 —— 立刻看见 → 确认几何无误、纯粹是可见性调参。

### 抓到 2 个真 bug（都是"测试测的是没人调用那条路"）
1. **静态赛道碰撞体从来没进过物理世界**：`registerTrackBodies` 全文只被 `track.js` 的
   `generateTrack()` 调用，而浏览器走的是 `buildWorld()` → `track.build()`。
   physics.js 里唯一的 `world.addBody` 是给车的（地面是解析约束）。
   => **护栏 / 桥栏 / 桥墩全是纯视觉装饰**，车直接穿过去飞出赛道（正是规格抱怨的穿模）。
   修：`RacePhysics` 构造里 `registerTrackBodies(world, track, barrierMaterial)`。
2. **桥墩扎穿下层路面**：`lat = ±(hw-1.2) = ±5.8m`（按**桥面**半宽算），但柱子是从地面顶到桥面的。
   实测 20 根里 **18 根立在下层沥青上**，最严重距下层路中心线仅 **0.95m**（桥下净空 1.89m）。
   修：新增 `Track._groundLatAbs(x,z,groundY)`（只在**同层**采样点里找最近点，
   常规 `sample()` 在立交处会命中另一条腿），按它迭代外推到 ±(hw+3.5)=±10.5m。
   实测：0 根穿模，净空 **21.03m** ✓
