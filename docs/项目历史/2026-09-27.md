## 坑与手法（可复用）
- **CDP 真机验收是"样式真的生效"的唯一证据**：selftest 只能证明代码里有那段字符串，
  证明不了面板真的是 340px、blur 真的生效。手写 CDP 客户端（WebSocket + Runtime.evaluate）
  约 60 行，**不需要 puppeteer/playwright**，符合零依赖红线。
- **⚠️ `getBoundingClientRect().width` 对带 `transform: translateX(102%)` 的元素会返回 0**
  （滑出动画的 transform 影响 rect）。测宽度必须读 `getComputedStyle(el).width`。
- **`display:none` 的元素无法 `focus()`**：`#hudChatBar` 挂在 `#hud` 内，
  非比赛态 `#hud.hidden` ⇒ 焦点测试必须先摘掉 `#hud.hidden`（这不是 bug 是真实态）。
- **无头窗口默认 `document.hasFocus()===false`**，需先 `Page.bringToFront` + `window.focus()`。
- **拦截"假绿"的写法**：断言前先做**反证**（非打字态 throttle 必须 = 1），
  否则 `throttle === 0` 在"赛车根本没在跑"时也会通过。
- **窗口级按键旁路 + 输入框 stopPropagation 必须同时存在**，少一个就会出现
  "打字即抖动"或"Enter 双触发"。

## §一 五连发车灯与倒计时死锁（main.go + main.js/network.js）

  → 严格 1000ms 间隔 `COUNTDOWN_TICK{val:3/2/1}` → 归零 `RACE_START{at}`。
  新增常量 `countdownTickMs = 1000`。**Go `sync.Mutex` 非可重入** ⇒ 阶段切换前必须先
  `r.mu.Unlock()` 再进下一段睡眠循环（P0 自死锁保护，本轮守住）。
- **双通道冗余**：新权威（`START_SEQUENCE_BEGIN`/`COUNTDOWN_TICK`/`RACE_START`）与旧
  （`count*`/`lights stage*`/`start`）并行下发 ⇒ e2e/selftest 旧守卫不破。
- 客户端 `S.controlsLocked`（默认 `true`）是**独立**于 `!S.rp.racing` 的第二道放行闸；
  `sampleLocalInput` 判据串 `!S.rp || !S.rp.racing || car.raceLocked || S.controlsLocked`。
  `showStartLights(stage)`：stage3→前 3 红灯 / 4→第 4 / 5→第 5 / ≥6→红灯全灭+绿灯
  +`controlsLocked=false`+620ms 后隐遮罩。
- **统一放行入口 `forceRaceGo(reason)`**（`_raceGoDone` 一次性）：三条路径（权威

## §四 FM8 级护栏接触导向与偏摆力矩（physics.js）★ 踩坑最多
- `applyBarrierGuidance(dt)` 严格按规格实现：`tangent = normal.cross(up).normalize()`
  （对齐速度方向）、restitution=0 + 切向保留、`theta<60°` 时 `yawImpulse = sgn *
  min(theta,0.8) * speed * m * 0.15 / m` 写入 `angularVelocity.y`；几何防吸附
  `pen>0.005` 时沿法线内推 `(pen+0.03)`（`_guidanceDone` 去重）。
- **★★ 最大陷阱：0.9 切向保留绝不能每物理子步都乘**。60Hz×2s ⇒ `0.9^120 ≈ 3e-6`
  ⇒ **贴墙即死**（`verify_sec3` 会报"脱离过程车没动起来"）。
  正解：`fresh = !car._wallContact` —— **仅首次接触子步**乘 0.9；持续接触改用
  `clamp(1 - GUIDANCE_TANGENT_FRICTION(0.35)*dt, 0, 1)` 逐帧微衰减；无接触时重置
  `_wallContact=false`。修复后 verify_sec3 回到 43/43。
- 新增 CFG：`GUIDANCE_TANGENT_KEEP:0.9` / `GUIDANCE_TANGENT_FRICTION:0.35` /
  `GUIDANCE_THETA_MAX:60°` / `GUIDANCE_THETA_CAP:0.8` / `GUIDANCE_YAW_GAIN:0.15` /
  `GUIDANCE_OUT_EPS:0.03` / `GUIDANCE_MIN_SPEED:0.35`。
