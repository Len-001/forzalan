## 二、服务端修复（`main.go`，4 项 P1）

| # | 缺陷（基线行为） | 修复后行为 |
| --- | --- | --- |
| 1 | 慢客户端积压时丢"最旧帧"，可能丢掉 `start` / `RACE_START` / `end` 等控制帧，且无补发机制 | 出站队列拆为双通道：`send`（控制帧，**永不丢**）与 `snaps`（位姿/排位/在线状态，满则丢新帧，16ms 后下一拍自带新数据）；`writePump` 控制帧优先，避免被 60Hz 位姿流饿死 |
| 2 | `leave()` 判空后解锁，`join()` 可在此窗口挤入，随后房间被 delete + shutdown，新玩家落入**无 ticker 的孤儿房间** | 新增 `Room.draining` 标记，在持 `rm.mu` 时置位；`attachLocked` 拒绝一切回收中的房间 |
| 3 | `kick` 只发报文不断连接，被踢者若不自行跳转会**永久留在 `hub.clients`**（心跳清理只覆盖房间成员） | `time.AfterFunc(2s, target.close)` 延迟断开，留足 `kicked` 报文写入时间 |
| 4 | AI 罚时链路断裂：客户端只对 `isLocal` 车上报 `pen`，服务端 `pen` 处理器只记发送者自身 → **AI 罚时/违规次数恒为 0** | 客户端对 AI 车上报 `{t:'pen', id}`（不进本地 HUD）；服务端 `pen` 改走 `botTargetLocked`，与 `state`/`lap`/`finish` 同一套权威 |

## 三、车辆物理（`public/js/physics.js`，参考 VitaVehicle 思路）

基线版本的横向抓地是**硬钳位**：容量以内全额消除侧向速度、超容量全额保留——抓地-滑移关系是一条不连续的阶跃，既没有峰值抓地窗口，也没有大滑移的衰减。

### 新增内容

1. **滑移率抓地曲线 `slipGripFactor(deg)`**
   - 上升段（0° → 8°）：smoothstep 从 0.92 升到 1.0 —— 小侧偏"咬住"路面，入弯中段抓地最足
   - 衰减段（> 8°）：指数收敛到 0.74 —— 漂移中车尾"滑"而不"甩崖"，反打方向能救回来
   - 衰减段在 8° 处恰好等于 1.0，与上升段无缝衔接（无折角）

2. **摩擦椭圆耦合**
   - 驱动空转 / 重刹 / 手刹占用纵向摩擦容量，按 `sqrt(1 - µ·share²)` 削减侧向可用抓地
   - 效果：重刹进弯转向变钝、大油门出弯推头——同一条物理定律推出

3. **规格兜底保持不变**：规格 §四要求的动摩擦下限（侧向 µ ≥ 0.45 量级）仍是最外层钳位，"完全侧滑时像在冰面平移"的回归路径不受影响

### 可调参数（`physics.js` 顶部 CFG）

```js
SLIP_PEAK_DEG: 8,        // 峰值抓地对应的侧偏角（度）
SLIP_PEAK_GAIN: 0.92,    // 0° 侧偏时的抓地保留比例（直线行驶基线）
SLIP_FALLOFF_KEEP: 0.74, // 大滑移侧的抓地收敛下限
FRICTION_ELLIPSE: 0.55,  // 摩擦椭圆耦合强度
```

> 当前参数是**保守首版**（0° 保留 0.92，非常接近旧行为）。想要更硬核的手感可下调 `SLIP_PEAK_GAIN` / `SLIP_FALLOFF_KEEP`，但需重跑 AI 行为检查。

## 四、引擎声替换（自研振荡器 → 开源波导物理模型）

### 选型结论

| 候选 | 结论 |
| --- | --- |
| **Antonio-R1/engine-sound-generator**（MIT） | ✅ **采用**。唯一做气缸级物理仿真的方案：每缸进气/排气/歧管三段数字波导、气门按曲柄角开闭、点火脉冲激励、多支路消音器。`throttle`/`rpm` 是 AudioParam，与游戏驱动方式天然吻合 |
| cemrich/js-motor-sound-generation（MIT） | ❌ 否决。随机波形表 + 变速循环播放，使用已废弃的 ScriptProcessorNode，无法区分气缸架构 |
| russellmcc/soundfxweb 等 | 与引擎声无关 |

### 实现架构

| 音源 | 方案 |
| --- | --- |
| 本地车 · 活塞档（i6gt / v8 / v12） | **波导物理模型**（AudioWorklet）。气缸数 6/8/12 + 管路几何决定音色差异：V8 排气更长、消音器更重 → 低频厚；V12 管路短 → 高亢 |
| 本地车 · FE 电动档 | 保留原谐波振荡器（正弦/三角波电驱啸叫，无气缸物理可依） |
| 远端车 / AI（最多 8 个声源） | 保留振荡器 + HRTF panner（12 份波导模型 CPU 扛不住，且空间音频验收依赖 panner 行为） |
| worklet 不可用 / 加载失败 | 自动回落振荡器栈，旧浏览器不受影响 |

### 关键工程点

- 新增自包含 worklet 文件 `public/js/engine-sound-worklet.js`（上游代码合并为单文件、去除 three.js 依赖、保留 MIT 归属注释）
- **采样率自适应**：波导长度按 `sampleRate/44100` 缩放，任意采样率下音高一致（原版硬编码 44100）
- **CSP 兼容**：页面 CSP 为 `script-src 'self'`，AudioWorklet 必须自托管（`blob:` 会被拦），worklet 作为静态资源嵌入 exe 正好满足
- **音量实测标定**：新增 `tools/audio-calibrate.mjs`，6000rpm 满油门实测 RMS——增益 3.0 时削波（RMS 0.95 / peak 0.99），调到 **1.2** 后 RMS 0.68，与旧路径参照（0.54）同量级


