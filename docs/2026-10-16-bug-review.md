# Bug 复查报告（2026-10-16）

本轮针对上一版新增的联机、赛道位置、复位和输入流程做复查，共复现并修复 5 处缺陷。修复与回归测试随源码一并提交。

| 问题 | 触发条件与影响 | 修复 |
| --- | --- | --- |
| 旧包覆盖赛况 | P2P 新包先到、服务器旧包后到；旧包的位姿被拒收，但圈数、罚时、幽灵状态仍被应用 | Worker 只对缓冲接受的包更新赛况，避免信息倒退及碰撞掩码错误 |
| 跨线复位虚增进度 | 起终点线前离开赛道，跨线后复位到线前旧锚点；原实现保留跨线后的累计次数，名次虚增近一圈 | 合法路面锚点同时保存累计跨线次数，复位时一起恢复 |
| 逆向跨线虚增进度 | 累计跨线次数为 0 时逆向跨越样条接缝，旧实现将负数钳到 0 | 允许有符号跨线次数，反向经过接缝保持位置连续 |
| P2P 提前建连 | 本端配置请求尚未完成，对端准备信令先到；连接使用空 ICE 配置，可能无法穿透 NAT | 等待配置加载后处理建连；快速开关时旧配置请求不得覆盖新状态 |
| 旧协商误关新连接 | 旧协商仍在等待，玩家关闭并重新开启 P2P；旧操作的错误回调关闭同 ID 的新连接 | 按连接对象校验异步结果，过期结果、候选与消息不能影响新连接 |

前四类复现用例（包括旧包回退）在修复前实际运行失败，修复后通过；旧协商竞态同样先复现失败，再修复验证。
