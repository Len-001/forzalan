# 极限竞速 · LAN（forzalan）

> 一个**面向局域网联机的网页端拟真赛车**。Go 单文件服务端把全部前端资源编译期内嵌，浏览器即客户端；**运行期零外部网络请求**，断网路由器下开箱即用。

---

## 项目定位

本项目参照《Forza Motorsport》系列的驾驶手感与赛事规则，自行实现了一套完整的**联机拟真赛车系统**：固定步长车辆动力学、服务端权威房间管理、状态同步与误差收敛、赛道程序化生成、赛事裁决（罚时 / DNF / 幽灵车）。

**技术选型原则：零第三方构建依赖。** 前端不引入打包器与 npm 依赖（three.js 与 cannon-es 以单文件形式内置），服务端仅依赖 Go 标准库，验证脚本全部为纯 Node `.mjs`。

> ⚠️ **声明**：本项目为独立技术研究项目，与 Microsoft Corporation、Turn 10 Studios 无任何关联、未获其授权或赞助，不含任何官方游戏资源或代码。"极限竞速"、"Forza" 等名称与商标归各自权利人所有。

## 核心特性

| 能力 | 实现要点 |
|---|---|
| **多人联机** | 单房间上限 12 席；4 位房间号；房主权威的赛道 / 圈数 / 模式切换并实时广播 |
| **状态同步** | Dual-Layer 误差融合 + 20 Hz 指数衰减 `exp(-20dt)`；远端车辆以 KINEMATIC 代理插值，位移超限与 Jerk 尖峰实测为 0 |
| **车辆动力学** | Web Worker 内独立固定步长积分；悬挂、轮胎、气流（尾流）、路肩起伏 |
| **碰撞与护栏** | 护栏碰撞体厚 2.0 m ＋ 单子步位移上限 0.03 m；200 km/h 正面撞墙法向反弹实测 1.146 → 0.0071 m/s（不穿透、不弹飞） |
| **赛事裁决** | 脱困复位回到**驶出赛道前最后一个合法位姿**（罚时 +3.0 s 并 3.5 s 幽灵化）、最佳走线作废、首位冲线后 60 s DNF 宽限倒计时 |
| **赛道** | 铃鹿 8 字 / 拉斯维加斯夜赛 / 斯帕 / 新手·极简高速环道；几何可由 OpenStreetMap 数据导入器生成 |
| **辅助系统** | F1 风格计时塔（实时秒差与罚时列）、车手名牌、最佳走线显示、程序化引擎声（AudioWorklet 波导） |
| **可验证性** | 79 个 `.mjs` 验证脚本 + Go 单测，覆盖几何、物理、网络、渲染与 UI 层；含负对照组（negative control）反证断言有效性 |

## 技术架构

```
浏览器（12 客户端）
├── 渲染层      three.js（内置单文件）
├── 主循环      main.js  —— 渲染帧 / 输入 / 相机 / 赛事 UI
├── 物理层      physics.js  →  physics.worker.js（独立 Web Worker，固定步长）
├── 求解器      cannon-es（内置单文件）＋ Baumgarte 补丁
└── 网络层      network.js（WebSocket）＋ RemoteSnapshotBuffer（远端插值）
        │
        │  WebSocket（JSON 信令 + 二进制快照）
        ▼
Go 服务端（单文件可执行）
├── HTTP 静态服务     //go:embed all:public  内嵌全部前端资源
├── 房间管理          创建 / 加入 / 席位 / 准备 / 权威配置广播
├── 权威时钟          起跑倒计时、红灯序列、圈数与完赛判定
└── 结算              罚时累计、DNF 判定、成绩归属

原生 C++ 层（开发期验证用，不参与运行时）
├── safe_physics / safe_collision   求解器与碰撞安全边界
├── timesync / race_delta           时序同步与秒差算法
├── rb_replicator                   刚体状态复制与混合
└── wasm/                           Emscripten 桥接（wire 格式 + TS 类型定义）
```

**权威划分**：服务端持有房间状态、起跑时刻与最终成绩；车辆动力学由各客户端本地以固定步长演算，远端状态经误差融合收敛。这是"客户端预测 + 服务端权威"的常用折中——**代价是极端网络抖动下远端车辆可能出现短暂视觉偏差，收益是本地操控零延迟**。

## 快速开始

### 前置条件

- **Go 1.21+**（构建服务端）
- 现代浏览器：Chrome / Edge 97+、Firefox 102+、Safari 16.4+
- *可选*：Node.js（运行验证脚本）、Emscripten 与 CMake（重建 WASM）

### 构建

```bash
# 在仓库根目录执行；public/ 会经 go:embed 一并打进二进制
go build -o forzalan.exe .
```

> 说明：验证脚本与原生 harness 不是运行必需项，仅用于回归验证。当前仓库不包含编译产物。

### 运行

```bash
./forzalan.exe
```

启动后控制台会打印本机与局域网访问地址：

```
  ┌───────────────────────────────────────────────────────────┐
  │   极限竞速 · LAN   12人局域网 3D 网页赛车（全离线单文件）  │
  └───────────────────────────────────────────────────────────┘

   本机访问      http://localhost:8099
   局域网访问    http://192.168.100.148:8099      ← 把这个地址给同学
```

**命令行参数**

| 参数 | 默认 | 说明 |
|---|---|---|
| `-addr` | `:8099` | 监听地址，如 `-addr :9000` |
| `-laps` | `3` | 默认圈数 |
| `-quiet` | `false` | 关闭逐帧日志（比赛时更清爽） |

端口优先级：`-addr` > 环境变量 `PORT` > `8099`。

> 默认端口选用 `8099` 而非 `8080`，因为 `8080` 常被 Steam 的 `steamwebhelper`（CEF 调试端口）占用。

## 局域网联机

1. **房主**双击运行 `forzalan.exe`，将控制台「局域网访问」那行地址发给其他玩家。多网卡时选与对方同网段的 `192.168.x.x`。
2. **其他玩家**在浏览器打开该地址（**必须走 `http://`，不要用 `file://` 打开 HTML**），填写昵称、车身颜色。
3. 房主点「创建房间」，将顶部 4 位房间号告知他人；他人填入房间号加入。
4. 全员点「准备」→ **5 秒整备倒计时 + 250 ms 载入缓冲 + 5×700 ms 红灯序列**后自动发车，无需房主额外操作。

**首次运行需放行防火墙**（勾选「专用网络」）。若误点拒绝，其他玩家会卡在「正在探测服务端…」。

> 想先自己练手：大厅内「单机练习（11 台 AI 车手 · 不联网）」不占端口、无需他人。

更多细节见 [`docs/联机部署指南.md`](docs/联机部署指南.md)。

## 操作方式

| 按键 | 功能 |
|---|---|
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车（停住后继续按 = 倒车） |
| `A` `D` / `←` `→` | 转向 |
| `空格` | 手刹（漂移） |
| `C` / `V` | 切换视角（追尾 → 引擎盖 → 鸟瞰） |
| `R` | 脱困复位（回到出界前合法位姿，罚时 +3.0 s，3.5 s 幽灵化） |
| `L` | 最佳走线显示开关 |
| `M` | 音效开关 |
| `←` `→` | 完赛后切换观战对象 |

## 验证与测试

仓库自带分层验证体系，全部为**零第三方依赖**的纯 Node 脚本，可直接运行：

```bash
# 服务端单测
go test ./...

# 综合自检（几何 / 物理 / 网络 / UI 断言）
node tools/selftest.mjs

# 端到端联调（编译产物 + 真实 WebSocket 客户端）
node tools/e2e.mjs

# 赛道几何证据自检
node tools/track-verify.mjs

# 原生 harness（需 C++ 工具链）
bash native/run_tests.sh
```

完整脚本清单与用途见 [`工具脚本索引.md`](工具脚本索引.md)。

## 已知问题

项目方记录第三轮改动后 `selftest.mjs` 出现 **4 项断言未通过**（711 / 715），改动方向正确但量未达阈值，**未做回退**：

| # | 未通过的断言 | 实测 | 阈值 |
|---|---|---|---|
| 1 | 直线段走线居中 | 1.34 m 偏移 | < 1.0 m |
| 2 | `steer=+1`（D/→）向右侧移 | 2.58 m | > 3 m |
| 3 | `steer=-1`（A/←）向左侧移 | 2.58 m | > 3 m |
| 4 | 沙地全油门脱困提速 | 峰值 18.0 km/h | 35~110 km/h |

其余门禁全绿（`e2e` 128/128、`verify_sec3` 47/0、`track-geometry-audit` 20 种子全通过等）。详见 [`变更对比_v2_v3.md`](变更对比_v2_v3.md)。
